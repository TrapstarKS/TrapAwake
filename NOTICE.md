# Attribution and third-party notices

TrapAwake is an independent, personally maintained fork of
[Insomnia](https://github.com/krishhgg/Insomnia), originally developed by
**Krish Garg (krishhgg)**. The original MIT license and copyright notice are
preserved verbatim in [LICENSE](LICENSE). The original Git history is retained.

The selected base is `b6a7499c183b82eb30b5e969489e6a7420250eea`, fetched on
October 13, 2026. Its latest stable ancestor release is Insomnia 0.1.0;
TrapAwake 0.2.0 starts an independent release series.

The preserved base also contains contributions by Batuhan Aydin, nsd97 and
Danish Rafie. Their commit authorship is retained. The reusable battery and
thermal monitor, owner-only file utilities, session formatting, login item
support, duration input, keyboard capture, and legacy recovery code
originate in that history.

The six community pull requests requested for evaluation are documented in
[the audit](docs/trapawake-audit.md). They were inspected at specific head
commits; none was cherry-picked wholesale. The explicit unlimited-session
and compact-menu concepts informed the fork requirements. The assertion
lifecycle and simplified interface were implemented for this fork.

TrapAwake is not an official Insomnia release and is not affiliated with or
endorsed by its original maintainers. No upstream pull request, mandatory
compatibility promise, or automatic upstream synchronization is part of this
project.

There are no external Swift package dependencies. Apple frameworks and SF
Symbols are used through the macOS SDK; they are not redistributed as
third-party binaries. Historical Insomnia artwork is retained with its
source and tests; the shipped TrapAwake icon is generated by its own AppKit
script.
